# Explore published bulk data

These download sites provide access to producers' published GKM datasets.
Follow each site's instructions to choose a release, format, and update method.

## Downloads

| Resource | Description | Download site |
| --- | --- | --- |
| ClinVar-GKM | ClinVar variation and clinical interpretation data represented with GKM standards. The official download site provides monthly full releases, weekly deltas, and typed Parquet files, with instructions for downloading and querying the data. | [Explore ClinVar-GKM downloads](https://dataexchange.clinicalgenome.org/clinvar-gkm/data-access/download/) |
