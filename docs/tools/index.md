# Pillar II: Tools

GKM standards define shared models for genomic variation and related knowledge.
Implementers need tools to construct, validate, and work with GKM-standard data.
**This pillar shows how GKM data can be created and used in practice.**

## Explore the GKM tools

<div class="grid cards" markdown>

- :material-code-json: [**Reference implementations**](reference-implementations.md)

    Use standards-specific Python libraries to construct and validate GKM models.

- :material-package-variant-closed: [**GKM Toolkit**](gkm-toolkit/index.md)

    Use the Python package for loading, exploring, and exchanging GKM
    Bundles, schemas, and the genomic knowledge objects they contain.

</div>

!!! note "GKM tools are optional"

    The Python reference implementations and GKM Toolkit are provided to help implementers work with GKM-standard data. Neither is required to use GKM. Implementers can use other languages and tools as long as their data conforms to the relevant GKM standards.
