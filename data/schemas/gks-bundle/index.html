    Title: GKS Bundle
    Type object
    Required No
    Additional properties Any type allowed

    Description: A GKS Bundle packages modular GKS objects (variants, conditions, propositions, statements) into a single shareable, schema-validated document. This is a self-contained demonstrator of the Pillar 1 packaging pattern: it uses local $defs rather than remote GA4GH $refs so the site build stays hermetic and offline-reproducible. The production bundles will compose the real remote GKS schemas.

    Title: Proposition
    Type object
    Required Yes
    Additional properties Any type allowed
    Defined in #/$defs/Proposition

    Description: A possible fact about a subject, expressed as subject-predicate-object. GKS prescribes several specialized propositions (e.g. VariantPathogenicityProposition); a CustomProposition (a planned Pillar 2 escape hatch) fills the gap for propositions GKS does not prescribe.

    Property Pattern Type Deprecated Definition Title/Description

    + predicate No string No - The relationship asserted between subject and object.
    + object No object No - The entity related to the subject via the predicate (e.g. a condition).
